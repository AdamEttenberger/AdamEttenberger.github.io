Personal portfolio website containing projects and demos.

# Vue 3 + Vite Project

## Recommended IDE

- Visual Studio Code 

## Project Setup

```
npm install
```

### Compile and Hot-Reload for Development

```
npm run dev
```

> [!NOTE]
> VSCode Launch (default hotkey: F5)

### Compile and Minify for Production

```
npm run build
```

### Preview Production Build Locally

```
npm run preview
```
